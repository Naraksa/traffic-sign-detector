# 🚦 Cambodian Traffic Sign Detection System (ML Pipeline)

## 📌 Project Overview
This project develops a **machine learning-based traffic sign detection system** tailored for **Cambodian roads**, with **Khmer language output (text + audio)**.

The system will:
- Detect traffic signs using YOLOv8
- Display bounding boxes + class labels
- Output Khmer text and audio
- Run on webcam/video for real-time demo
